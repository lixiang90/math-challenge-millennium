# `millennium_riemann_hypothesis`

Millennium Prize: Riemann Hypothesis

- Problem ID: `millennium_riemann_hypothesis`
- Test Problem: no
- Submitter: lean-dojo/LeanMillenniumPrizeProblems contributors
- Notes: The target is the critical-line formulation for every nontrivial zero of the Riemann zeta function.
- Source: https://github.com/lean-dojo/LeanMillenniumPrizeProblems/tree/fd5207106c8c13c40cd4eeb0acb169c2c4e58aeb/Problems/RiemannHypothesis/Millennium.lean
- Informal solution: Prove that every nontrivial zero of the Riemann zeta function has real part 1/2.
